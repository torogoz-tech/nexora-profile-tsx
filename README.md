# Nexora TSX analysis profile

This repository independently maintains the declarative Nexora profile for TSX (`tsx`). It recognizes the documented TypeScript/JSX subset without executing components or claiming complete TypeScript or React semantics.

The four YAML contracts define the profile, while fixtures and verification notes define tested support. Validate with a compatible `nexora-api` `0.1.0` engine. Profile version: `0.1.0`.

## Architecture and stewardship

Nexora's architecture and the independent profile model are led by [Abner Velasco](https://www.linkedin.com/in/abnervelasco/), who is also responsible for the ongoing maintenance and evolution of this profile repository. Profile changes remain independently versioned, tested, and reviewed.
